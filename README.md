# ProsperoPkgTool

A native .NET 10 toolkit for PS5 (Prospero) packages. It reads, extracts, verifies, and
builds debug packages, with no Sony tools and no native dependencies.

> **Experimental:** Packages generated by ProsperoPkgTool have been validated and compared on PC, but they have not been tested on a jailbroken PS5. A successful build or validation does not guarantee that a package will install, launch, or play correctly on real hardware. Keep backups and use generated packages at your own risk.

## Status

The reader is verified byte for byte against a real Sony built debug package:

- FIH/CNT header parsing and segment geometry
- key derivation (`ComputeKeys` / EKPFS) from the content id and passcode
- outer PFS AES-128-XTS key ladder and decryption
- superblock verification and `sce_sys/keystone` checks
- inner image parsing, so listing and extracting individual files works
- building debug base and application packages with `img_create` (stored or Kraken)

Packages built here verify and extract on PC against this project's own reader. Independent
cross-implementation validation is **not** currently reproducible in-tree: the
`tools/CrossValidate.ps1` oracle is being repaired against the current LibProsperoPkg API, and the
retail cross-checks are opt-in. No PS5 hardware install or launch has been demonstrated.

## Verification levels

"Verified" is only used with its scope stated:

- **Structurally parsed** — FIH/CNT/LIH/PFS envelopes and ranges are read and bounds-checked.
- **Internally round-tripped** — bytes written by this project are read back by this project (internal
  consistency, not independent proof).
- **Fixture parity** — specific fields are byte-compared against a checked-in Sony-built debug package.
- **Independently cross-validated** — a different implementation decodes the same artifact; requires the
  repaired oracle harness and is not currently reproducible in-tree.
- **Cryptographically verified** — RSA/ECDSA signature verification is not implemented.
- **Hardware tested** — not performed; no PS5 install/launch evidence exists.

`img_verify` reports each check as `PASS` / `FAIL` / `UNAVAILABLE` / `UNSUPPORTED` / `ERROR` and an
overall `PASSED` / `FAILED` / `INCOMPLETE` outcome. A missing key is `UNAVAILABLE`; a decode, crypto, or
I/O failure after the payload opens is `ERROR` (a failure), and is never softened to `UNAVAILABLE`.

## Build

```powershell
dotnet build .\ProsperoPkgTool.slnx -c Release
```

The CLI lands in `ProsperoPkgTool\bin\Release\net10.0\ProsperoPkgTool.exe`.

## Testing

```powershell
dotnet test .\ProsperoPkgTool.Tests\ProsperoPkgTool.Tests.csproj -c Release
```

The suite covers internal read/write/verify round-trips (internal consistency, not independent
proof), Sony-fixture parity against a checked-in real package, and regression fixtures. Independent
cross-implementation cross-reads require the repaired `tools/CrossValidate.ps1` oracle. Three
tests are **opt-in** and skipped in a normal run because they need a locally supplied retail package
(they are not repository fixtures):

- `ProsperoNapsLayoutTests.RetailPackage_NapsLayout_RoundTripsByteExact`
- `ProsperoNapsLayoutTests.RetailPackage_CblockInfo_AllEntriesRoundTripByteExact`
- `TempSliceExtractTests.Extract_TargetDataBlocks`

To run them, place a retail package at the path referenced in the test (for example
`C:\Users\User\Desktop\New folder\ps5 pkg\PPSA03530-bd-nw.pkg`) and remove its `Skip =` argument.

## Commands

Run the exe with no arguments for the full list. The main ones:

Reading:

```powershell
ProsperoPkgTool.exe pkg-detect .\title.pkg
ProsperoPkgTool.exe native-info .\title.pkg
ProsperoPkgTool.exe native-decrypt .\title.pkg --passcode <32 chars> --out .\inner.bin
ProsperoPkgTool.exe img_info .\title.pkg
ProsperoPkgTool.exe img_file_list .\title.pkg --passcode <32 chars>
ProsperoPkgTool.exe img_extract .\title.pkg .\out --passcode <32 chars>
ProsperoPkgTool.exe img_verify .\title.pkg
```

Building:

```powershell
ProsperoPkgTool.exe img_create .\source --out .\title.pkg --passcode <32 chars>
ProsperoPkgTool.exe img_create .\project.gp5 --out .\title.pkg
ProsperoPkgTool.exe convert .\backup --out .\title.pkg --passcode <32 chars>
ProsperoPkgTool.exe fself .\eboot.elf --out .\eboot.bin
```

`img_create` builds a debug package from a source folder or a GP5 manifest. `convert` does
the same for a decrypted backup, swapping in the raw ELF modules, fake signing them, and
printing a launch readiness report. Add `--compression kraken` to pack the inner image.
`formats` lists the container backends, and `compare` diffs two packages field by field.
GP5 helpers: `gp5gen`, `gp5info`, `gp5validate`, `gp5format`, `source-validate`,
`playgo-info`.

## GUI

`ProsperoPkgTool.Gui` is a WinForms front end that drives the same CLI. Select a package,
pick an operation, press F5.

## Notes

Debug packages are keyed to the console passcode, and retail consoles reject them because
there is no Sony signing. Update/patch (LIH), delta, and DLC building are not implemented, and
retail finalization is intentionally out of scope (it needs Sony key material). The next
implementation priorities are **update/patch (LIH) writing**, then **DLC**.
