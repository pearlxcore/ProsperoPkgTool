# ProsperoPkgTool

A .NET 10 toolkit for PS5 (Prospero) packages. It reads, extracts, verifies, and
builds FPKGs, with no proprietary tools and no native dependencies.

It is also the package library for PS5 PKG Tool.

> **Experimental:** FPKGs generated by ProsperoPkgTool have been validated and compared on PC, but they have not been tested on a jailbroken PS5. A successful build or validation does not guarantee that an FPKG will install, launch, or play correctly on real hardware. Keep backups and use generated packages at your own risk.

## Status

The reader is checked against a reference FPKG. The headers, keys and tables match byte for byte:

- FIH/CNT header parsing and segment geometry
- key derivation (`ComputeKeys` / EKPFS) from the content id and passcode
- outer PFS AES-128-XTS key ladder and decryption
- superblock verification and `sce_sys/keystone` checks
- inner image parsing, so listing and extracting individual files works
- building base and application FPKGs with `img_create` (stored or Kraken)

FPKGs built here verify and extract on PC with this project's own reader. An FPKG built by
LibProsperoPkg 1.2.0 is also read back byte for byte in `ProsperoPkgTool.CompatibilityTests`. The
fuller `tools/CrossValidate.ps1` check is still being repaired against the current LibProsperoPkg
API, and the retail PKG checks are opt-in. Nothing has been installed or launched on a PS5.

## Verification levels

"Verified" is only used with its scope stated:

- **Structurally parsed** - FIH/CNT/LIH/PFS envelopes and ranges are read and bounds-checked.
- **Internally round-tripped** - bytes written by this project are read back by this project (internal
  consistency, not independent proof).
- **Fixture parity** - specific fields are byte-compared against a checked-in FPKG.
- **Independently cross-validated** - a different implementation reads the same FPKG; in-tree this is the
  LibProsperoPkg 1.2.0 fixture in `ProsperoPkgTool.CompatibilityTests`, while the fuller oracle is not
  yet reproducible.
- **Cryptographically verified** - RSA/ECDSA signature verification is not implemented.
- **Hardware tested** - not performed; no PS5 install/launch evidence exists.

`img_verify` reports each check as `PASS` / `FAIL` / `UNAVAILABLE` / `UNSUPPORTED` / `ERROR` /
`NOTPRESENT`, and an overall `PASSED` / `FAILED` / `INCOMPLETE` outcome. A missing key is
`UNAVAILABLE`; a decode, crypto, or I/O failure after the payload opens is `ERROR` (a failure),
and is never softened to `UNAVAILABLE`.

## Build

```powershell
dotnet build .\ProsperoPkgTool.slnx -c Release
```

The CLI lands in `ProsperoPkgTool\bin\Release\net10.0\ProsperoPkgTool.exe`.

## Testing

```powershell
dotnet test .\ProsperoPkgTool.Tests\ProsperoPkgTool.Tests.csproj -c Release
```

The suite covers internal read/write/verify round-trips (internal consistency, not independent
proof), fixture parity against a checked-in FPKG, and regression fixtures. Fuller
cross-implementation cross-reads use the `tools/CrossValidate.ps1` oracle, which is being repaired.
Three tests are **opt-in** and skipped in a normal run because they need a locally supplied retail
PKG (they are not repository fixtures):

- `ProsperoNapsLayoutTests.RetailPackage_NapsLayout_RoundTripsByteExact`
- `ProsperoNapsLayoutTests.RetailPackage_CblockInfo_AllEntriesRoundTripByteExact`
- `TempSliceExtractTests.Extract_TargetDataBlocks`

To run them, place a retail PKG at the path referenced in the test (for example
`<path to a retail PKG such as PPSA03530-bd-nw.pkg on your machine>`) and remove its
`Skip =` argument.

`ProsperoPkgTool.CompatibilityTests` is a separate tracked project that cross-reads an FPKG built
by LibProsperoPkg 1.2.0 (`Fixtures/lpp120-mixed.pkg`) byte for byte through both the materialized and
lazy readers, and covers the sparse-index cases. `ProsperoPkgTool.Diagnostics` is a small console
that dumps raw NAPS records and a verification report as JSON. Run them the same way.

## Commands

Run the exe with no arguments for the full list. The main ones:

Reading:

```powershell
ProsperoPkgTool.exe pkg-detect .\title.pkg
ProsperoPkgTool.exe native-info .\title.pkg
ProsperoPkgTool.exe native-decrypt .\title.pkg --passcode <32 chars> --out .\inner.bin
ProsperoPkgTool.exe img_info .\title.pkg
ProsperoPkgTool.exe img_file_list .\title.pkg --passcode <32 chars>
ProsperoPkgTool.exe img_extract .\title.pkg .\out --passcode <32 chars>
ProsperoPkgTool.exe img_verify .\title.pkg
```

Building:

```powershell
ProsperoPkgTool.exe img_create .\source --out .\title.pkg --passcode <32 chars>
ProsperoPkgTool.exe img_create .\project.gp5 --out .\title.pkg
ProsperoPkgTool.exe convert .\backup --out .\title.pkg --passcode <32 chars>
ProsperoPkgTool.exe fself .\eboot.elf --out .\eboot.bin
```

`img_create` builds an FPKG from a source folder or a GP5 manifest. `convert` does
the same for a decrypted backup, swapping in the raw ELF modules, fake signing them, and
printing a launch readiness report. Add `--compression kraken` to pack the inner image.
`formats` lists the container backends (the FPKG now; exFAT, FFPKG and FFPFSC are planned),
and `compare` diffs two packages field by field.
GP5 helpers: `gp5gen`, `gp5info`, `gp5validate`, `gp5format`, `source-validate`,
`playgo-info`.

## GUI

`ProsperoPkgTool.Gui` is a WinForms front end that drives the same CLI. Select a package,
pick an operation, press F5.

## Notes

FPKGs are keyed to the console passcode, and retail consoles reject them because
they are not properly signed. Update/patch (LIH), delta, and DLC building are not implemented, and
retail finalization is intentionally out of scope (it needs the real key material). The next
implementation priorities are **update/patch (LIH) writing**, then **DLC**.
