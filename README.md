# ProsperoPkgTool

A native .NET 10 toolkit for PS5 (Prospero) packages. It is all clean room: no Sony
binaries, no GPL code, no copied source. The parsers, crypto, and filesystem readers are
written from scratch based on my own reverse engineering notes.

The point of the project is to build debug packages that install and run on a jailbroken
PS5 without using Sony's `prospero-pub-cmd.exe`. It is not meant to pass Sony's official
publishing validation, and it never will without Sony's private keys.

> **Experimental:** Packages generated by ProsperoPkgTool have been validated and compared on PC, but they have not been tested on a jailbroken PS5. A successful build or validation does not guarantee that a package will install, launch, or play correctly on real hardware. Keep backups and use generated packages at your own risk.

## What works

Reading is the mature part. It has been checked byte for byte against a real Sony built
debug package, and against a couple of independent readers:

- FIH/CNT header parsing and segment geometry
- key derivation (`ComputeKeys` / EKPFS) from the content id and passcode
- outer PFS AES-128-XTS key ladder and decryption
- superblock verification and `sce_sys/keystone` checks
- inner image reading, so listing and extracting individual files works
- building debug base/application packages with `img_create` (stored or Kraken)

Packages we build verify and extract cleanly, including by the reference engine and by
Sony's own tool. A few fine details still differ from Sony (some undocumented fields,
keystone derivation, patch building), but they do not stop the output from working on PC.

## Build

```powershell
dotnet build .\ProsperoPkgTool.slnx -c Release
```

No submodules and no native dependencies. The CLI lands in
`ProsperoPkgTool\bin\Release\net10.0\ProsperoPkgTool.exe`.

## Commands

Run the exe with no arguments for the full list. The main ones:

Reading:

```powershell
ProsperoPkgTool.exe pkg-detect .\title.pkg
ProsperoPkgTool.exe native-info .\title.pkg
ProsperoPkgTool.exe native-decrypt .\title.pkg --passcode <32 chars> --out .\inner.bin
ProsperoPkgTool.exe img_info .\title.pkg
ProsperoPkgTool.exe img_file_list .\title.pkg --passcode <32 chars>
ProsperoPkgTool.exe img_extract .\title.pkg .\out --passcode <32 chars>
ProsperoPkgTool.exe img_verify .\title.pkg
```

Building:

```powershell
ProsperoPkgTool.exe img_create .\source --out .\title.pkg --passcode <32 chars>
ProsperoPkgTool.exe img_create .\project.gp5 --out .\title.pkg
ProsperoPkgTool.exe convert .\backup --out .\title.pkg --passcode <32 chars>
ProsperoPkgTool.exe fself .\eboot.elf --out .\eboot.bin
```

`img_create` takes a source folder or a GP5 manifest and builds a debug package. `convert`
does the same for a decrypted backup, swapping in the raw ELF modules, fake signing them,
and printing a launch readiness report. Add `--compression kraken` to pack the inner image.
`formats` lists the container backends and `compare` diffs two packages field by field.
There are also GP5 helpers (`gp5gen`, `gp5info`, `gp5validate`, `gp5format`,
`source-validate`, `playgo-info`).

## GUI

`ProsperoPkgTool.Gui` is a small WinForms front end that drives the same CLI. Point it at
a package, pick an operation, press F5.

## Notes

Debug packages are key locked to the console passcode, and retail consoles still reject
them since there is no Sony signing. Patch, delta, and DLC writing are not implemented.
